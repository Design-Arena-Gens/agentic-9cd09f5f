# Ritam Reviews Dashboard

A clean, modern, and highly intuitive SaaS dashboard designed for hotel managers in India to unify online reviews from multiple platforms into a single, actionable interface.

## 🚀 Live Demo

**Production URL:** https://agentic-9cd09f5f.vercel.app

## ✨ Features

### Two-Column Layout
- **Left Column (Review Feed):** Scrollable list of recent reviews with:
  - Star ratings (★★★★☆)
  - Source icons (Google, MakeMyTrip, Booking.com, TripAdvisor)
  - Guest names
  - Review snippets
  - Sentiment indicators (Green for Positive, Red for Negative, Grey for Neutral)

- **Right Column (Details & Actions):** When a review is selected:
  - Full review text displayed clearly
  - AI Sentiment Analysis section showing:
    - Overall sentiment assessment
    - Key points extracted from the review
    - AI-generated suggested response
  - Action buttons to use or edit the suggested response

### Design Highlights
- Clean, modern UI with Tailwind CSS
- Responsive layout optimized for desktop and tablet
- Interactive review cards with hover effects
- Color-coded sentiment indicators for quick visual scanning
- Professional typography and spacing
- Smooth transitions and interactions

## 📚 Technology Stack

- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🛠️ Local Development

1. Navigate to the project directory:
```bash
cd ritam-reviews-dashboard
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open http://localhost:5173 in your browser

## 📦 Building for Production

```bash
npm run build
```

The build output will be in the `dist` directory.
